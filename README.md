min(HN) is for reading [Hacker News](https://news.ycombinator.com/), minimally. While Hacker news is high-signal, it can be used to waste time, like most other social media. There are usually only a few important posts for any given person, with most being ignorable.

min(HN) is designed to be used at most once a day. It displays the top 10 posts each day. This is not configurable.
